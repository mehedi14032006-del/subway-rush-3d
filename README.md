# SUBWAY RUSH 3D

An asset-backed 3D endless runner built with **Three.js**, real rigged **GLB 3D characters, subway trains, city buildings & props** (CC0 Kenney + Three.js), a custom **dynamic curved-world GLSL vertex shader**, real **WAV sound effects + dynamic soundtrack**, and automated **Capacitor Android APK** builds.

## Features
- **Real 3D GLB Assets (Offline Bundled in APK):** Rigged Skater Boy, Skater Girl, Cyber Bot, and Inspector Guard; Electric Subway Trains, Bullet Express Trains, City Metro Trains, Freight Container Cars, Detailed Tracks, Commercial Skyscrapers, and Industrial Railyard Scenery.
- **Dynamic Curved-World Shader:** Smoothly bends the horizon downward and curves left/right as you sprint, applied seamlessly across skinned characters, instanced rails, trains, and buildings.
- **Full Endless Runner Mechanics:**
  - Instant mobile swipe controls with input buffering + air-slam quick drop.
  - Boarding ramps to sprint across train rooftops + oncoming express trains.
  - Stumble & Inspector chase mechanic.
  - Double-tap **Hoverboard** shield with shockwave explosion on crash.
  - **Jetpack**, **Coin Magnet**, **Super Sneakers**, **2x Multiplier**, and **Key Revive ("Save Me!")**.
  - Persistent Coin Shop (upgrade power-up durations, unlock runners & hoverboards) and Mission Multiplier progression.

## Build Locally or Download APK
1. Open the **Actions** tab on GitHub.
2. Open the latest **Build Android APK** workflow run.
3. Download the **`subway-rush-3d-apk`** artifact, extract `app-debug.apk`, and install on Android.
